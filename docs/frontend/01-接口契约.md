# 前后端接口契约

本文是 Python 和 Java 后端共同遵守的协议，具体实现请查看对应后端目录。

## 基础约定

- 路由前缀：`/auth`、`/system`、`/monitor`、`/common`、`/resource`。
- 成功和业务失败统一返回 `{"code": int, "msg": str, "data": T | null}`。
- 分页数据统一为 `{"rows": [...], "total": N}`。
- 认证请求头：`Authorization: Bearer <token>` 与 `clientid`。
- 日期时间格式：`yyyy-MM-dd HH:mm:ss`。
- 雪花 ID 超出 JavaScript 安全整数范围时序列化为字符串。
- 业务错误通常使用 HTTP 200，通过响应体 `code` 表示业务结果；路由 404/405 和健康探针异常使用真实 HTTP 状态码。

## 认证和权限

登录接口为 `POST /auth/login`，验证码为 `GET /auth/code`，菜单路由为 `GET /system/menu/getRouters`，当前用户信息为 `GET /system/user/getInfo`。

菜单权限串采用 `模块:实体:操作` 格式，例如 `system:user:add`。前端只负责隐藏无权限按钮，后端必须再次校验权限。

## 实现差异

| 能力 | Python | Java |
| --- | --- | --- |
| 会话存储 | Redis 中保存会话和权限快照 | Sa-Token/Redis 保存登录会话 |
| 请求事务 | `db_getter` 管理异步事务 | Spring 事务管理 |
| 迁移 | `app/alembic/versions/` | `src/main/resources/db/migration/` |
| 配置 | `env/.env.*` + 环境变量 | `application-*.yml` + Spring 环境变量 |

新增接口时先保证本页契约不变，再在对应后端文档中实现技术栈细节。
