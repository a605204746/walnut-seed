# Python 配置说明

配置加载顺序为：代码默认值 < `env/.env.<ENVIRONMENT>` < 进程环境变量。Docker 镜像不包含 `env/`，容器部署应使用 compose 环境变量。

## 必须关注的配置

| 变量 | 开发默认值 | 生产要求 |
|---|---|---|
| `ENVIRONMENT` | `dev` | `prod` |
| `SERVER_HOST` / `SERVER_PORT` | `0.0.0.0` / `8011` | 按网关拓扑设置 |
| `SECRET_KEY` | 示例值 | 随机、至少 32 字节，禁止包含 `change-me` |
| `DATABASE_HOST/PORT/USER/PASSWORD/NAME` | localhost/3306/root/空/`walnut_seed_python` | 使用专用账号和库 |
| `REDIS_HOST/PORT/PASSWORD` | localhost/6379/空 | 生产按网络策略启用密码 |
| `PROD_CORS_ORIGINS` | 空 | 填真实前端域名，逗号分隔 |
| `ALLOWED_HOSTS` | `[*]` | 限制为实际域名 |
| `LOGGER_LEVEL` | `DEBUG` | 推荐 `INFO` |
| `DATABASE_ECHO` | `True` | 必须关闭 |

## 安全与接口

- `HTTPS_REDIRECT` 控制 HTTPS 跳转；TLS 通常在 nginx 或网关终结。
- `TRUSTED_PROXY_IPS` 决定是否信任 `X-Forwarded-For`，反向代理部署必须按实际拓扑填写。
- `API_DECRYPT_ENABLED`、`API_DECRYPT_PUBLIC_KEY`、`API_DECRYPT_PRIVATE_KEY` 控制接口加解密；密钥无效时生产启动会拒绝或自动停用加密。
- `CAPTCHA_ENABLE`、`PASSWORD_MAX_RETRY_COUNT`、`PASSWORD_LOCK_TIME` 分别控制验证码和登录失败锁定。
- `MAX_FILE_SIZE` 默认 10MB，`MAX_REQUEST_SIZE` 默认 20MB。

## 运行时目录

本地直接启动时日志写入仓库根目录 `data/logs/walnut-seed-python.log`，上传文件写入 `data/upload/`。Docker 启动时 `/data/logs` 绑定到宿主机 `docker/volumes/logs/`，上传目录仍在容器内部。
