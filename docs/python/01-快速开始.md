# Python 后端快速开始

本文用于在本机启动 Python 后端并完成第一次接口验证。默认环境为开发环境，生产部署请阅读 `10-Docker部署.md` 和 `11-生产上线清单.md`。

## 1. 前置环境

| 依赖 | 建议版本 | 检查命令 |
|---|---|---|
| Python | 3.12+ | `python --version` |
| uv | 最新稳定版 | `uv --version` |
| MySQL | 8.0+ | `mysql --version` |
| Redis | 7+ | `redis-cli --version` |

项目默认连接 `localhost:3306` 的 MySQL 和 `localhost:6379` 的 Redis。没有本机服务时，先启动公共中间件：

```bash
docker compose -f docker/docker-compose.middleware.yml up -d
```

## 2. 安装和配置

```bash
cd walnut-backend-python
uv sync
cp env/.env.example env/.env.dev
```

按实际环境修改 `env/.env.dev`，至少确认数据库、Redis 和 `SECRET_KEY`。开发环境可以使用仓库示例密钥，生产环境必须替换为随机的 32 字节以上密钥。

## 3. 初始化数据库

开发环境手动执行迁移：

```bash
uv run main.py upgrade --env dev
```

该命令只执行 Alembic 迁移，不会启动 Web 服务。种子数据由应用生命周期按幂等方式初始化。

## 4. 启动和验证

```bash
uv run main.py run --env dev
```

启动后访问：

- Swagger：`http://127.0.0.1:8011/docs`
- ReDoc：`http://127.0.0.1:8011/redoc`
- 存活检查：`GET http://127.0.0.1:8011/common/health/check`
- 就绪检查：`GET http://127.0.0.1:8011/common/health/ready`

默认账号为 `admin / admin123`。登录接口需要 `clientid` 请求头，完整请求和响应格式见 `04-接口契约.md`。

## 5. 常用命令

```bash
uv run pytest                         # 全量测试
uv run pytest tests/test_auth_session.py -q
uv run ruff check .                   # 静态检查
uv run ruff format .                  # 格式化
uv run main.py current --env dev     # 查看迁移版本
uv run main.py history --env dev     # 查看迁移历史
```

开发模式会启用 Uvicorn reload。生产环境不要使用 reload，也不要把 `DEBUG`、`DATABASE_ECHO` 保持为开发默认值。

## 6. 启动失败排查

1. 数据库连接失败：确认 MySQL 已启动、端口为 3306，且 `DATABASE_*` 与实际账号一致。
2. Redis 连接失败：确认 Redis 已启动，检查 `REDIS_HOST`、`REDIS_PORT` 和密码。
3. 迁移失败：先执行 `uv run main.py current --env dev`，检查 `alembic_version`，不要直接删除历史迁移文件。
4. 路由审计失败：新接口缺少认证依赖时应用会拒绝启动，应补充 `AuthPermission` 或加入明确白名单。
