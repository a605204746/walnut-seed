# Java 配置说明

Spring Boot 配置以 `application.yml` 为基础，`application-dev.yml` / `application-prod.yml` 按 profile 覆盖；容器环境优先使用 Spring relaxed binding 环境变量。

## 必须关注的配置

| 配置 | 默认值 | 生产要求 |
|---|---|---|
| `server.port` | `8011` | 与 nginx upstream 一致 |
| `spring.profiles.active` | Maven profile 注入 | 明确使用 `prod` |
| `sa-token.jwt-secret-key` | 示例值 | 使用随机生产密钥 |
| `spring.datasource.dynamic.datasource.master.*` | 本机 MySQL | 使用专用账号、限制网络 |
| `spring.data.redis.host/port/password` | localhost/6379/空 | 按网络策略配置 |
| `captcha.enable` | `true` | 生产建议保持开启 |
| `api-decrypt.enabled` | `true` | 配置生产 RSA 两对密钥 |
| `logging.config` | `classpath:logback-plus.xml` | 保持文件日志轮转 |

## 环境变量示例

```bash
SPRING_PROFILES_ACTIVE=prod
SERVER_PORT=8011
SPRING_DATA_REDIS_HOST=redis
SPRING_DATA_REDIS_PORT=6379
SPRING_DATASOURCE_DYNAMIC_DATASOURCE_MASTER_USERNAME=app
SPRING_DATASOURCE_DYNAMIC_DATASOURCE_MASTER_PASSWORD='replace-me'
# 本地启动使用仓库根目录 data/logs；Docker 由 compose 注入容器日志目录
LOG_PATH=../data/logs
```

## 日志和运行目录

本地直接启动时日志目录默认为仓库根目录 `data/logs/`，文件名为 `walnut-seed-java-console.log`、`walnut-seed-java-info.log`、`walnut-seed-java-error.log`，按天轮转并压缩历史文件。Docker 启动时容器目录 `/walnut-backend/server/logs` 绑定到宿主机 `docker/volumes/logs/`。

## 配置变更后检查

1. 检查 profile 是否真正生效，启动日志应显示 `prod`。
2. 修改数据库或 Redis 后访问 `/common/health/ready`。
3. 修改 RSA 密钥后重新验证 `encrypt-key` 请求头及响应。
4. 修改端口后同步 compose healthcheck 和 nginx upstream。
