# Java 后端快速开始

本文用于在本机启动 Java 后端并完成第一次接口验证。默认使用 Spring Boot 开发配置，生产部署请阅读 `10-Docker部署.md` 和 `11-生产上线清单.md`。

## 1. 前置环境

| 依赖 | 建议版本 | 检查命令 |
|---|---|---|
| JDK | 25 | `java -version` |
| Maven | 3.9+ | `mvn -version` |
| MySQL | 8.0+ | `mysql --version` |
| Redis | 7+ | `redis-cli --version` |

没有本机 MySQL/Redis 时，先启动公共中间件：

```bash
docker compose -f docker/docker-compose.middleware.yml up -d
```

## 2. 配置和启动

```bash
cd walnut-backend-java
mvn spring-boot:run
```

默认端口为 `8011`，数据库为 `walnut_seed_java`。启动时 Flyway 自动执行 `src/main/resources/db/migration/` 下的版本脚本，数据库不存在时由 JDBC URL 自动创建。

开发配置位于 `src/main/resources/application-dev.yml`，生产配置位于 `application-prod.yml`。推荐通过环境变量覆盖敏感配置，不要把生产密钥提交到仓库。

## 3. 验证服务

- OpenAPI：`http://127.0.0.1:8011/swagger-ui.html`
- 存活检查：`GET http://127.0.0.1:8011/common/health/check`
- 就绪检查：`GET http://127.0.0.1:8011/common/health/ready`

默认账号为 `admin / admin123`。登录接口需要 `clientid` 请求头，统一响应格式见 `04-接口契约.md`。

## 4. 常用命令

```bash
mvn test
mvn -DskipTests package
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

查看迁移状态请检查数据库中的 `flyway_schema_history` 表；不要修改已执行的 `V__*.sql` 文件，应新增更高版本迁移。

## 5. 启动失败排查

1. Flyway 失败：检查 `flyway_schema_history` 和最新迁移脚本，修复后新增版本，不要删除历史记录。
2. 数据库连接失败：确认 `spring.datasource.dynamic.datasource.master.*` 配置和 MySQL 权限。
3. Redis 连接失败：确认 `spring.data.redis.host/port/password`，容器环境使用服务名 `redis`。
4. 端口冲突：通过 `SERVER_PORT` 或 `server.port` 修改端口，并同步前端代理配置。
